# コード説明

指定されたコード・ファイル・アーキテクチャについて説明する。コードの変更は行わない。

## 手順

1. 説明対象を特定する:
   - 引数が指定されていればそのファイル / 関数 / 概念
   - 指定がなければユーザーに確認する
2. **explainer サブエージェント** に以下の調査・説明を委譲する:
   - **何をしているか**: 機能・目的の概要
   - **どう動いているか**: 処理フロー、主要なロジック
   - **なぜこう設計されているか**: 設計判断の理由（推測を含む場合は明示）
   - **依存関係**: インポート、呼び出し元 / 呼び出し先
3. explainer の説明を受け取り、ユーザーに報告する

## ルール

- コードの変更・改善提案はしない（聞かれた場合のみ）
- 推測と事実を明確に区別する
- 専門用語を使う場合は簡潔に補足する

## 引数

`$ARGUMENTS` が指定された場合、その対象について説明する。ファイルパス、関数名、概念名のいずれも受け付ける。
