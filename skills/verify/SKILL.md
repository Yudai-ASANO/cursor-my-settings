# /verify — 完了前検証

「完了した」と宣言する前に、証拠を揃える。主張の前に証拠。

## 手順

1. 検証スコープを特定する:
   - 引数が指定されていればその範囲
   - 指定がなければ未コミットの変更全体
2. **verifier サブエージェント** に以下の検証を委譲する:
   - ビルド確認（エラー・警告が0であること）
   - テスト実行（全テストパス + 新規テスト追加の確認）
   - 静的解析（lint・型チェック・フォーマッター）
   - 要件照合（元の要件/タスクとの1対1確認）
   - 差分確認（デバッグコード・秘密情報の混入チェック）
3. Verification Report を受け取り、結果を報告する
4. 1つでも FAIL があれば「完了」と宣言しない

## ルール

- 検証コマンドを**実際に実行**する（「おそらく通るはず」は禁止）
- 1つでも FAIL があれば「完了」と宣言しない
- 検証結果のコマンド出力を証拠として含める
