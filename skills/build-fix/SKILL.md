# /build-fix — ビルドエラー修正

ビルド/コンパイルエラーを最小限の変更で解決する。

## 手順

1. ビルドコマンドを実行してエラーを収集する
2. **generator サブエージェント** に以下の制約付きで修正を委譲する:
   - ビルドエラーの修正**のみ**。リファクタリング・改善は禁止
   - **最小限の diff** で修正する — アーキテクチャ変更をしない
   - 1つ修正するごとにビルドを再実行し、エラー数の減少を確認する
   - 全エラー解消後、テストスイートを実行して既存テストが壊れていないことを確認する
3. generator の修正結果を受け取り、報告する

## ルール

- ビルドエラーの修正**のみ**行う。リファクタリング・改善は禁止
- 型の `any` や `@ts-ignore` での回避は最終手段（理由をコメントで記述）
- 3回試行して解決しない場合はユーザーに報告して停止する

## 引数

`$ARGUMENTS` が指定された場合、そのエラーメッセージ/ファイルに対して修正を適用する。
