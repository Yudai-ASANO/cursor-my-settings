# /review — コードレビュー

未コミットの変更または指定されたコードを多角的にレビューする。

## 手順

1. レビュー対象を特定する:
   - 引数が指定されていればそのファイル/範囲
   - 指定がなければ `git diff` で未コミットの変更を取得
2. **qa-reviewer サブエージェント** に以下の評価を委譲する:
   - Correctness — 要件通りに動作するか
   - Completeness — エッジケースが処理されているか
   - Code Quality — 読みやすく保守しやすいか
   - Safety — セキュリティ問題・エラーハンドリング
   - Testing — テストの存在と妥当性
3. PASS/FAIL の判定結果を報告する
4. FAIL の場合は具体的な修正指示を含める

## ルール

- レビュー中にコードを変更しない
- 「概ね問題なし」は禁止 — 具体的な判定を行う
- CRITICAL/HIGH の問題があればコミット前に修正を促す

## 引数

`$ARGUMENTS` が指定された場合、その対象をレビューする。ファイルパス、PR番号、または説明文を受け付ける。
