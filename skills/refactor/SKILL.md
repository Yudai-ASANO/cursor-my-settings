# /refactor — リファクタリング

既存コードの構造を改善する。機能は変更しない。

## 手順

1. リファクタリング対象を特定する
2. **architect サブエージェント** に現状分析とリファクタリング方針の策定を委譲する:
   - 現在の構造の問題点
   - 改善後の構造の提案
   - トレードオフの分析
3. 方針をユーザーに提示し、同意を得る
4. 同意後、以下の順序でリファクタリングを実行する:
   1. 既存テストが全パスすることを確認する
   2. リファクタリングを適用する
   3. テストを再実行し、全パスを確認する
   4. 必要に応じてテストを追加する

## ルール

- 機能の追加・変更をしない（振る舞いを保持する）
- テストがパスする状態を常に維持する
- 大きな変更は小さなステップに分割する

## 引数

`$ARGUMENTS` が指定された場合、その対象をリファクタリングする。
